## 👨‍💻 About Me

I'm a Junior Software Developer and Multiplatform Application Development (DAM) graduate with hands-on experience in professional web development and backend environments.

During my internship at **CETEMET**, I worked on the development and expansion of an internal ERP module using Astro, JavaScript and Tailwind CSS. Previously, at **CodeArts**, I supported backend development with PHP and Symfony, working also with Docker, SQLite and DynamoDB.

I'm currently focusing on backend development with **Java and Spring Boot**. I've developed and deployed a REST API featuring database persistence, authentication, automated testing and interactive API documentation.

I also hold a **Cambridge C1 Advanced English certification**.

## 🚀 Featured Projects


- **Task Manager API** — Deployed REST API built with **Java 21 and Spring Boot**, featuring CRUD operations, filters, search, pagination, DTO validation, centralized error handling and automated tests with JUnit, Mockito and MockMvc.

  Uses **Spring Security (HTTP Basic)** to protect write operations, **Docker** for containerization and cloud-hosted **MySQL (Aiven)** for persistence. Documented with **Swagger/OpenAPI**.
